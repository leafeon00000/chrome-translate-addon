# 対訳ビューア（→日）Chrome 拡張機能

開いている外国語ページを **左=原文／右=日本語訳** の2画面で、**レイアウト・画像をそのまま保ったまま**読み比べるための Chrome 拡張機能です。翻訳元の言語は**自動判別**（または手動選択）し、**翻訳先は日本語固定**です。
翻訳には **Chrome 138+ 内蔵の Translator API（オンデバイス翻訳）** を使用します。APIキー不要・無料・オフライン動作で、要件の「Chromeのgoogle翻訳」に最も近いエンジンです。

## 仕組み（iframe実体方式）

ツールバーアイコンをクリックすると、現在表示中のページのDOMをスナップショットし、左右2枚の `<iframe srcdoc>` に**実体ごと描画**します。
- 左iframe = 原文をそのまま描画
- 右iframe = 同じ描画を**文（センテンス）単位の `<span>` に分割**し、各文を英→日翻訳で上書き

翻訳時は左右の文を同じ通し番号（`data-tv-sid`）の `<span>` でラップします。左右は同一スナップショットを同じアルゴリズムで分割するため番号が一致し、**文単位で左右が1対1に対応**します（ハイライト連動に利用）。

区切りは**ブロック要素（`<p>` など）単位**で行います。ブロック内のテキストをインライン要素（`<a>` `<b>` 等）を無視して連結し、ツールバーで選んだ**翻訳単位**に応じて区切ります（**文単位**＝連結テキストを文に分割／**まとまり単位**＝ブロック全体を1単位）。連結してから区切るため `I went to <a>the store</a> today.` のように**リンクや装飾をまたぐ文も1単位としてまとめて**扱えます。1文が装飾をまたぐ場合、**左ペインは装飾（リンク等）を保持**したまま同一 `sid` の複数 `<span>` に分割し、ハイライトは全断片を同時に点灯します。**右ペイン（訳）はプレーン訳**とし、訳文を先頭 `<span>` にまとめます（またいだ箇所の装飾は失われます）。

`srcdoc` は親ページと同一オリジン扱いのため、内部DOMへ直接アクセスして翻訳でき、外部CSS・画像も読み込まれるので**レイアウト・画像が保持**されます。

## 機能

- 現在のページを左右2画面に、元のレイアウト・画像そのままで表示
- **翻訳元の言語を自動判別**（Chrome 内蔵 Language Detector API）。誤判定や非対応時に備え、ツールバーの言語フィールドで**手動選択**も可能。翻訳先は日本語固定
- **アイコンクリックでモデルDL済みなら、そのまま自動で（文単位）翻訳を開始**。未DLの初回はブラウザのユーザー操作要件のため自動DLできないので、「翻訳開始」ボタンを押してDL＋翻訳する
- 「翻訳開始」ボタンで英→日翻訳を実行し、右画面のテキストを順次置き換え（周囲のCSS・画像は維持）
- **翻訳単位を「文単位／まとまり（段落）単位」から選択可能**（ツールバーのセレクト）。まとまり単位は文脈が増えるぶん訳質が上がり、ハイライトも段落単位になる。**翻訳後に単位・言語を変えて「翻訳開始」を押せば、スナップショットから作り直して何度でも再翻訳できる**（実行中のみ操作を固定）。再翻訳時は**読んでいたスクロール位置を保持**する
- **左画面（英語原文）の単語にマウスオーバーすると、訳と辞書をカーソル近傍にツールチップ表示**（単語ホバー辞書）。まず Translator の機械翻訳を即表示し、Chrome 内蔵 Prompt API（Gemini Nano）が使える環境では**品詞＋意味（複数）の辞書**を遅れて追記する2段階表示。「翻訳開始」で準備した翻訳エンジンを流用するため、翻訳開始後に有効になる
- マウスオーバーした箇所と、その左右の対応箇所が同時にハイライト（ベストエフォート）。**翻訳後は選択した単位（文／段落）**、翻訳前は要素単位で光る
- 左右のスクロールが概ね連動（ベストエフォート）
- アイコン再クリック・「閉じる」ボタン・Esc キーで元のページに復帰

## 動作要件

- **Chrome 138 以降のデスクトップ版**（Edge / Firefox / Safari、モバイルは非対応）
- 初回利用時は英→日の翻訳モデル（数十MB）が自動ダウンロードされます。進捗はツールバーに表示されます。
- ネットワークやストレージの条件によってはモデルが利用できない（`unavailable`）場合があります。その際はツールバーにメッセージを表示します。
- 単語ホバー辞書の2段目（品詞＋意味）は Chrome 内蔵 **Prompt API（Gemini Nano）** を使います。対応バージョン・フラグ・ハードウェアを満たす環境でのみ有効で、満たさない場合は機械翻訳のみになります（また辞書は**原文が英語のときのみ**表示します）。
- 翻訳元の自動判別は Chrome 内蔵 **Language Detector API** を使います。**モデルDL済み（available）のときだけ**「翻訳開始を押した瞬間」に判定し、未DL・低確信・未対応時は手動選択の値（既定は英語）にフォールバックします。

## インストール（開発者モードで読み込み）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`chrome-translate-addon/`）を選択する

## 使い方

1. 英語などの外国語のニュース記事（画像つき）など本文量のあるページを開く
2. ツールバーの拡張アイコンをクリック → 左右2画面に元のレイアウト・画像そのまま表示される。**モデルDL済みならそのまま文単位翻訳が自動で始まる**（翻訳元は自動判別）
3. （必要なとき）ツールバーで**翻訳元の言語**（自動判別／手動選択）と**翻訳単位**（文単位／まとまり単位）を選ぶ（既定は自動判別・文単位）
4. 「翻訳開始」を押す → 初回はモデルDLの進捗が出たのち、右画面のテキストが日本語に置き換わる。翻訳後に単位を変えてもう一度押すと、作り直して再翻訳する
5. 左画面の英単語にマウスオーバーすると、その単語の訳がカーソル近くにツールチップ表示される
6. 文（またはまとまり）にマウスオーバーすると、その単位と左右の対応箇所がハイライトされる（翻訳前は要素単位）
7. アイコン再クリック・「閉じる ✕」・Esc で元に戻る

| --------------- | ------------------------------------------------------------------- |
| `manifest.json` | Manifest V3 定義（action / scripting / activeTab）                  |
| `background.js` | アイコンクリックで content.css / content.js を注入する service worker |

## 既知の制約 / 注意点

- **完全なレイアウト一致はできません。** 翻訳で日本語の文字数が変わるため、行の折り返しや要素位置が多少ずれます（レイアウトの骨格・画像そのものは保持されます）。
- **JS依存コンテンツは描画されないことがあります。** 安定描画のためスナップショットからスクリプトを除去しているため、SPAやJSで後から挿入される要素・遅延読み込み画像は表示されない場合があります。まずは記事系ページでの利用を想定しています。
- **厳格なCSPのサイトでは表示できないことがあります。** `frame-src 'none'` などを持つサイトでは `srcdoc` iframe 自体がブロックされる可能性があり、その場合はツールバーにメッセージを表示します。
- ハイライト連動・スクロール同期は、左右でレイアウトが異なるためベストエフォート（完全一致はしません）。
- **文の区切り・文単位翻訳はベストエフォートです。** 文分割は `. ! ?` を基準にするため、略語（`Mr.` `U.S.` 等）で誤分割することがあります。ブロックの判定はタグ名ベースのため、CSS で表示形式を変えた要素では区切りがずれることがあります。`<br>` は連結時に空白を補わないため、改行で区切られた行が連結される場合があります。文単位で翻訳するため、段落をまとめて訳す場合より文脈が限定され、訳がやや不自然になることがあります。
- **装飾をまたぐ文では、右ペイン（訳）側の装飾が失われます。** リンクや強調が文の途中にある場合、左ペインでは装飾を保持しますが、右ペインは訳を先頭にまとめるため、またいだ箇所のリンク等は表示されません。
- **翻訳できる言語ペアには限りがあります。** 翻訳元→日本語のモデルが用意されているペアのみ動作します（`Translator.availability` で確認し、未対応ならメッセージを表示）。未対応の場合は言語フィールドで別の言語を選ぶか、対応ペアのページでご利用ください。自動判別は短文・多言語混在で外れることがあるため、その場合は手動選択してください。
- **単語ホバー辞書はベストエフォートです。** 1段目の機械翻訳（Translator API）は単語単体のため文脈がなく不自然なことがあります。2段目の辞書（Prompt API / Gemini Nano）は **実験的なオンデバイスLLM** で、対応 Chrome バージョン・フラグ・ハードウェアによっては利用できず（その場合は機械翻訳のみ）、生成のため**遅延（数百ms〜数秒）や誤り（ハルシネーション）・出力形式の崩れ**が起こり得ます（崩れた場合は整形せずそのまま表示します）。Prompt API の正確な利用条件は Chrome のバージョンにより変わるため、環境により挙動が異なります。
- `chrome://` などの特権ページには注入できません。
